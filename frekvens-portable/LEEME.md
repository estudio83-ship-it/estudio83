# IKEA FREKVENS Portable (F1715) · despiece

Figura interactiva del altavoz desmontado, con las piezas flotando (sin base).
Medidas y datos tomados del desmontaje de iFixit (guía 130948) y de sus fotos.

- `frekvens-portable-light.html` / `frekvens-portable.html`: páginas listas (tema claro / oscuro).
- Pasa el cursor (o toca) para despiezar; flechas para recorrer los 10 conjuntos; Espacio abre/cierra; Escape monta.

Reconstruir y comprobar la geometría:

    node build.mjs --light
    node build.mjs
    node build.mjs --light --audit
