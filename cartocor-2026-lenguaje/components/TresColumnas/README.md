# TresColumnas

Tres ideas paralelas (2025, "Prueba Texto"). Cada columna tiene un encabezado dentro de una elipse dibujada a mano en el color de una unidad y un panel `arena` debajo.

**Qué aporta quien la usa:** tres encabezados (sobretítulo + título) y un texto breve de hasta 40 palabras cada uno.

- Las tres columnas siempre tienen igual ancho y alto.
- La elipse lleva dos trazos (4 pt y 2 pt) girados −4°/+3°, como la pill de título.
- Colores de elipse: elegir tres unidades distintas; si el contenido es de una sola unidad, usar su color en las tres.
- Paneles en `arena` (en 2025 eran grises: 2026 los pasa a arena cálida).
